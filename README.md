# Daybreak Planner
## Try it out!
Live demo is available here: [https://daybreak-planner-598464211339.us-west2.run.app](https://daybreak-planner-598464211339.us-west2.run.app)


The "Daily Purge" planner: A minimalist task manager that forces intentionality by wiping your slate clean every 24 hours.

## Productivity Value
Most task managers become graveyards for good intentions. Daybreak Planner operates on a strict non-retention principle—all data expires at midnight. This artificial constraint eliminates backlog anxiety and forces you to prioritize only what you can realistically accomplish today. It features priority sorting and efficiency metrics to keep you focused on execution.

## How to Run & Test
This project uses Vite and requires Node.js.

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the application, add a few tasks with different priorities, and watch the midnight countdown timer.
